## Installation

### Releases

You could go to the [Releases](https://github.com/JereIDE/JereIDE/releases) page to download any version of JereIDE.

**macOS 12+ and Windows 10+ required.**
Linux support is not planned in the near future.

### Build from source

```bash
# Clone the repository
git clone https://github.com/JereIDE/JereIDE.git
cd JereIDE

# or cargo run --release
cargo run

```

## FAQ

### How is this different from other editors?

Not really.

### Why is it called JereIDE?

Most of my projects start with “Jere”. I like naming projects after myself.

### What's "Compose" mode?

Right now it's just a placeholder that is getting UI updates but is not functional.

For the future, Compose mode might be an AI agent center, when AI features are added into JereIDE.
