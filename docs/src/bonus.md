# Bonus

Bonus features, easter eggs, experimental features, legacy debug widgets, and more!

## The Widget Palette

Press `Command/Ctrl+Shift+W` to open the Widget Palette. It was the foundation of the Find&Replace dialog you see right now. It is kept because it... looks nice!

## The User Menu

A dropdown appears if you click the round avatar button in the far right of the title bar.

It has three menu options: "Username", "Settings…", and "Star Us on GitHub".
The first option is non-functional, but the second and third work.
